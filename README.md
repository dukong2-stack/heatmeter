# 증시 온도계

국내 증시 과열 지표 8개를 평일마다 자동으로 모아, 폰 홈 화면에서 여는 앱으로 보여 줍니다.

| 지표 | 출처 | 판정 방식 |
|---|---|---|
| 코스피 PER·PBR | 한국거래소 | 최근 10년 평균 ±1 표준편차와 비교 |
| 버핏지수 | 한국거래소 시가총액 ÷ config.json의 명목 GDP | 120% 초과면 과열 |
| 신용거래융자 잔고 | 네이버 금융 증시자금동향 | 1년 최고치 근처 + 지수 상승 중이면 과열 |
| 투자자예탁금 | 네이버 금융 증시자금동향 | 한 달 새 급증하면 과열 |
| 예탁금 회전율 | 거래대금 ÷ 예탁금 | 최근 1년 중 상위 10%면 과열 |
| 공모주 청약 열기 | 38커뮤니케이션 | 1000:1 이상 비중·시초가 평균 |
| 코스닥 개인 거래비중 | 한국거래소 | 최근 3년 중 상위 20%면 과열 |

기준값은 `config.json`의 `rules`에서 바꿀 수 있습니다.

## 처음 설정 (한 번만)

### 1. 한국거래소 회원가입
한국거래소 정보데이터시스템(data.krx.co.kr)에서 무료로 회원가입합니다. 2025년 말부터 로그인해야 데이터를 받을 수 있습니다.

### 2. 저장소 만들기
1. GitHub 앱이나 github.com에서 새 저장소를 만듭니다. 이름은 예: `heatmeter`. **Public**으로 만들어야 무료로 웹앱을 열 수 있습니다.
2. 받은 압축 파일을 풀어 안의 파일을 모두 올립니다. 폰에서는 github.com 웹페이지의 **Add file → Upload files**가 편합니다.
   - `.github/workflows/update.yml`은 숨김 폴더라 폰 업로드에서 빠질 수 있습니다. 빠졌다면 **Add file → Create new file**에서 이름 칸에 `.github/workflows/update.yml`을 그대로 입력하고 내용을 붙여 넣으세요.

### 3. 비밀번호 등록 (Secrets)
저장소 **Settings → Secrets and variables → Actions → New repository secret**에서 두 개를 추가합니다.

- `KRX_ID`: 한국거래소 아이디
- `KRX_PW`: 한국거래소 비밀번호

Secrets는 공개 저장소에서도 다른 사람에게 보이지 않고, 실행 기록에도 가려져 나옵니다.

### 4. 쓰기 권한 확인
**Settings → Actions → General → Workflow permissions**에서 **Read and write permissions**를 선택하고 저장합니다.

### 5. 첫 수집 실행
**Actions** 탭 → **과열 지표 수집** → **Run workflow**를 누릅니다.
첫 실행은 10년치를 한꺼번에 받느라 10~20분 걸립니다. 이후에는 몇 분이면 끝납니다.

### 6. 웹앱 켜기
**Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/docs**로 고르고 저장합니다.
1~2분 뒤 `https://아이디.github.io/heatmeter/` 주소가 나옵니다.

### 7. 홈 화면에 추가
- 아이폰: Safari로 주소를 열고 공유 버튼 → **홈 화면에 추가**
- 안드로이드: Chrome으로 주소를 열고 메뉴 → **홈 화면에 추가**

## 자동 실행 시각
평일 18:30(장 마감 뒤 지수·PER·시가총액)과 다음 날 09:00(하루 늦게 나오는 예탁금·신용잔고)에 돕니다. 앱은 열 때마다 최신 파일을 다시 읽습니다.

## 문제가 생기면
- 앱 위에 노란 안내가 뜨면 해당 출처의 수집이 실패한 것입니다. 나머지 지표는 정상 갱신됩니다.
- **Actions** 탭에서 빨간 X가 있는 실행을 눌러 **데이터 수집** 단계의 로그를 보면 원인이 나옵니다.
  - `KRX_ID / KRX_PW 가 설정되지 않았습니다` → 3단계 확인
  - `KRX 로그인 실패` → 아이디·비밀번호 확인, 거래소 사이트에서 비밀번호 변경 요구가 있었는지 확인
  - `표 구조가 바뀌었습니다` → 네이버나 38커뮤니케이션 화면이 바뀐 것입니다. 로그를 Claude에게 보여 주면 고쳐 드립니다.
- 버핏지수 과거 추세를 더 길게 보려면 `config.json`의 `gdp`에 이전 연도 명목 GDP(조원, 한국은행 ECOS 국민계정)를 넣으세요.

## 알아둘 점
- PER·PBR은 한국거래소의 실적(후행) 기준입니다. 증권사가 발표하는 12개월 선행 PER과 숫자가 다릅니다.
- 시가총액은 코스피·코스닥 지수 구성 종목 기준이라 우선주 등은 빠집니다.
- 매매 판단을 대신하지 않습니다.
